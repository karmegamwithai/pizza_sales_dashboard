# 🍕 Pizza Sales Dashboard

A Python and Streamlit-based dashboard for analyzing pizza sales data with interactive visualizations and business insights. This project helps track revenue, orders, top-selling pizzas, and sales trends through an easy-to-use interface.

---

## 🚀 Features

- 📈 Sales and revenue analysis
- 🍕 Top-selling and least-selling pizzas
- 📅 Daily and monthly sales trends
- 📊 Interactive charts and filters
- 📌 KPI metrics and business insights

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly / Matplotlib

## ▶️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone <your-repository-link>
cd Pizza-Sales-Dashboard
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Streamlit App

```bash
streamlit run app.py
```
