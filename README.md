🍕 Pizza Sales Dashboard

A Python and Streamlit-based dashboard for analyzing pizza sales data with interactive visualizations and business insights. The dashboard helps track revenue, orders, top-selling pizzas, and sales trends in a simple and user-friendly interface.

🚀 Features
Sales and revenue analysis
Top-selling and least-selling pizzas
Daily and monthly sales trends
Interactive charts and filters
KPI metrics for business insights
🛠️ Tech Stack
Python
Streamlit
Pandas
Matplotlib / Plotly
▶️ Run the Project
Clone the repository:
git clone <your-repo-link>
Install dependencies:
pip install -r requirements.txt
Run the Streamlit app:
streamlit run app.py
📊 Dashboard Insights

The dashboard provides a clear overview of pizza sales performance, helping identify customer preferences, peak sales periods, and revenue growth opportunities.
